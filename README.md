## 📖 Overview

**Kana Master** is designed to take the friction out of learning Japanese phonetic scripts. Whether you're a complete beginner starting your Japanese journey or reviewing before diving into JLPT prep, Kana Master provides an interactive, gamified, and clean practice environment right in your browser.

No account or complicated build step required — just open the app, practice in bite-sized 20-question sessions, track your weakest characters, and unlock an official-style printable **Kana Master Certificate** once you achieve 100% mastery.

---

## ✨ Features

- **⚡ Fast, Bite-Sized Practice Sessions**: 20 targeted questions per session designed for maximum retention without burnout.
- **🔤 Comprehensive Character Sets**:
  - **Hiragana** (平仮名)
  - **Katakana** (片仮名)
  - **Mixed Mode** (Hiragana + Katakana)
- **🎯 Multiple Training Modes**:
  - **Multiple Choice (MCQ)**: Quick visual recall — choose the correct romaji reading.
  - **Typing Practice**: Active recall — type the romaji directly for deeper memorization.
- **📊 Comprehensive Mastery Dashboard**:
  - Real-time global mastery percentage calculation.
  - Identification of your **Most Frequent Mistakes** and **Slowest Characters**.
  - Interactive grid showing individual mastery level for every single kana.
- **🎓 Japanese Certification (賞状)**:
  - Unlock and personalize an official Japanese-style certificate when reaching 100% mastery.
  - Edit and save your name directly onto the certificate.
- **🌓 Dark & Light Modes**: Beautiful UI tuned for both day and night study sessions with seamless system or manual toggling.
- **💾 Local Persistence & Privacy**: All progress, accuracy stats, and completion metrics are stored directly in your browser (`localStorage`). No tracking, no external login required.
- **📱 100% Responsive & Offline-Ready**: Optimized for mobile phones, tablets, and desktops alike.

## 🚀 Getting Started

Because Kana Master is built as a zero-dependency, vanilla client-side application, you don't need `npm`, `yarn`, or any backend servers!

### Option 1: Live Demo
Launch the app instantly in your browser:
👉 **[Open Kana Master Live](https://ratul121.github.io/KanaMaster/)**

### Option 2: Run Locally
1. Clone this repository:
   ```bash
   git clone https://github.com/Ratul121/KanaMaster.git
   cd KanaMaster
   ```
2. Open `index.html` in your favorite web browser:
   - On macOS:
     ```bash
     open index.html
     ```
   - On Linux:
     ```bash
     xdg-open index.html
     ```
   - On Windows:
     ```bash
     start index.html
     ```
   - Or use VS Code's **Live Server** extension.
